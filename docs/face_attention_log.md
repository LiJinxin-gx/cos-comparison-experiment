# 人脸识别探索日志 — 统计式局部注意力系列

> 探索环境: venv_test_t (free-threaded Python 3.14, cp314t core/numpy)
> 数据集: ① 67 张证件照 (testdata/face) + face1/face2 验证
>          ② ORL (AT&T) 40x10 (testdata/orl/faces, 400 PGM)
> 本仓库计划: 探索数据与脚本将整理入 GitHub 仓库

## v1 — 反馈式双通道 (face_feedback.py)

- 被动+主动双通道 -> 标签统计 -> 交集重点区域 -> 位置捕获 -> 反馈调参
- 结果: face2 高纯 ✓; face1 失败 (环境干扰); 变体反馈调参 0.724-0.754

## v2 — 统计式局部注意力 (face_attention.py)

- 多参数对比点 (passive x3 + active x4 = 7 参数) -> 频率统计 -> 关键结构点
- 共训练 (训练+验证), 动态锁定目标区域, 区域外屏蔽, 集合覆盖比对
- C 加速: core.threshold_map + numpy 向量化 + 自由线程 18 workers
- 结果: **face1 李金鑫 ✓ / face2 高纯 ✓ (2/2)**; ORL 40x10 平均 0.328 (std 0.0225,
  3 轮, 随机基线 0.025)

## v3 — 结构描述符 + 多级融合 + 区域多尺度 + 自主修正

- 关键点结构描述符: 邻域(5x5)响应直方图(4桶)+均值/方差 (6维), 抗干扰匹配
- 多级频率阈值融合: 95/98 两级关键结构 -> 各组合独立锁定/打分 -> 投票+分数融合
- 自主修正: 多容差(3/2/1) x 多级关键点迭代锁定, 最高置信组合胜出
- 区域多尺度: 设计为锁定区域放大比对 (未在本次运行启用, 记录待办)

### v3 结果

- face1 -> 李金鑫 ✓ / face2 -> 高纯 ✓ (2/2, 融合分数 0.545/1.000 保持)
- ORL 40x10 (前 2 轮): 0.300 / 0.330 — 与 v2 持平 (未见提升)
- 性能: 自主修正 (2级x3容差=6 组合) 使 ORL 每轮耗时 ~3x, 完整评估未完成

### v4 — 区分性关键结构 + 描述符匹配 + 强度加权 + 高低层双向 (face_attention.py)

- 低层: 粗细双档对比点 (粗 60% + 细 75%, 同响应复用); 中层: 频率 + 类内集中度
- 高层: 区分性关键点 = 高频 且 类内集中; 高层驱动低层: 关键结构 -> 锁定区域 + 细档
- 比对: 描述符余弦过滤 + 强度加权集合覆盖; 自主修正 (多级 x 多容差)

### v4 结果与结论

| 变体 | face1 | face2 | ORL(1轮) | 结论 |
|---|---|---|---|---|
| 描述符匹配参与 | 蔡雨静 ✗ | 高纯 ✓ | - | 跨域描述符不匹配, 有害 |
| 集中度关键点(单样本) | 0 点 -> 回退 | - | 0 点 -> 回退 | 每类单样本无法算集中度 |
| 集中度关键点(ORL 5样本) | - | - | 0 点 -> 回退 | 位置级特征无类专属点, 过严 |
| 粗细双档向量 | 蔡雨静 ✗ | 高纯 ✓ | - | 细档计数破坏匹配 |
| 强度加权(绑定desc) | - | - | - | 未独立验证 |
| 最终保留态 | 李金鑫 ✓ | 高纯 ✓ | 0.30 | 回退纯位置覆盖+粗档=v3 基线 |

- 结论: v4 五项改进均未带来提升 (描述符跨域有害/集中度过严/双档破坏);
  保留机制 = 区分性关键点架构 + 高层驱动日志 (与 v3 基线一致 2/2)

## v5 — 结构优先双向匹配 (face_structure.py, numpy 向量化)

- 分层模板: L1 点描述符 + L2 点对结构模板 (相对位移量化, 位置无关)
- 双向: 正向签名查表+desc 批量相似 (numpy) ; 反向"联想脑补" = 匹配点对原图确认
- 加速: numpy 全向量化 (点对 triu_indices/签名查表/确认 broadcast) + 自由线程
  (本机无 CUDA — Intel Arc, 自由线程优先); ORL 1 轮 ~100s (Python 版超时)
- 打包安装: pip install . 0.4.4 成功

### v5 结果与结论

- face1/face2 (1-shot): 分数无类区分 (模板=单图自身结构, 无类结构定义)
- ORL (5-shot): 0.03 (近随机) — 点对签名 32 桶太粗, desc 平均化无类区分
- 反向确认逻辑缺陷: 匹配点对来自本图 -> 确认率恒真; 真正区分需
  "模板预测缺失点" 而非本图自检
- 结论: 结构模板需更细签名 (连续相对位移+多阶结构) 与类间区分性筛选;
  1-shot 场景不适合类结构模板

## v5.1 — 对称傅里叶核验证 (face_sym.py, 多进程)

- 假设: 核不对称 -> 对比点位置偏移 -> 结构匹配错位
- 实现: fourier 新参数 offsets 平移相位中心 (cos(2πf(x-c)/k), 中心对称核)
- 加速: ProcessPoolExecutor 多进程 (对比点提取/类打分); pkg_cos --target 安装
  (venv_test_t site-packages 锁损坏, 新 fourier 装独立目录)

### v5.1 结果 (假设证伪)

| 框架 | 非对称核 (原始) | 对称核 |
|---|---|---|
| 结构模板 (v5.1) | ORL 0.03 | ORL 0.025 (近随机) |
| 注意力+屏蔽 (v3框架) | face1 李金鑫 ✓ / face2 高纯 ✓ | face1 陈思婷 ✗ / face2 高纯 ✓ |

- 对称核在有效框架上造成退化 (face1 ✓->✗): 非对称核保留方向选择性,
  相位位置编码方向信息, 对结构匹配更有效
- 结论: 核不对称不是失败原因; 已回退非对称核 (基线 2/2)

## v6 — 层次化反向传播匹配 (face_backprop.py)

- 分层模板带参数: key=(参数组索引, 签名) 指针合并, 不同训练模式模板不混用
- 前向分层: L1 点 / L2 点对结构模板; 反向逐层传播 (L2->L1, 防空间变形)
- 记录每层 matched/unmatched 特征
- 反射式参数训练: 8 组 (窗口x百分位x阈值) 变体反馈, 条件刺激调参
  (命中率高 -> 阈值细粒度调高 0.80->0.86/0.95; 命中率低 -> 窗口调大+放宽)
- 分层载体: 模板按频率分层 (内部 dict -> 内存 sqlite -> 文件 sqlite)
- 加速: 响应缓存 + 自由线程; GPU: 本机无 NVIDIA/CUDA (Intel Arc)

### v6 结果

- 反射训练: 2 轮全部组命中率 1.00 -> 阈值逐轮细化 (机制明确工作)
- 模板库: 每参数组 32 模板 (签名桶全覆盖)
- 反向匹配: face1/face2 均输出最高分组 (组2), L2 匹配 495/547, L1 确认 100%
- 局限: 验证逻辑为"组选择"而非"人分类" (模板库是组共享非每人独立);
  ORL 命中率 200/200 非分类评估
- 结论: v6 机制 (分层带参/反射训练/逐层反向/分层载体) 全部落地运行;
  端到端分类需"每人独立模板库"重构 (签名 32 桶粒度仍为根本瓶颈)

## 结论与待办
